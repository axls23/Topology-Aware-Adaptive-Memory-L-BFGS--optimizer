Core Capabilities

Why ta-LBFGS?

Traditional L-BFGS uses fixed memory and ignores the landscape structure. We fix that.

Topology Awareness

Analyzes gradient landscape structure via condition number estimation and Euler characteristic to identify meaningful curvature regions.

Adaptive Memory

Dynamically resizes the curvature buffer per-layer: more memory for ill-conditioned regions, less for well-behaved zones.

Saddle Evasion

Detects saddle points via Lanczos eigenvalue probes and escapes with eigenvector-directed perturbations satisfying Zoutendijk descent.

Bilevel Optimization

Supports bilevel hyperparameter tuning with differentiable per-layer learning rates, weight decay, dropout, and attention temperature.

HF Integration

Plug-and-play with Hugging Face transformers. Fine-tune real LLMs like Qwen 2.5 and GPT-2 with topology-aware second-order methods.

3D Trajectory Viz

Real-time PCA-projected trajectory visualization with adaptive landscape mesh, pivot markers, and spectral guard events.

Curvature Pairs

03

Topology-Aware Filter

κ → mℓ = ⌈log₂(κ)⌉ clamped to [3, 20]

m_l = compute_memory_size(kappa, m_base, m_min, m_max)
04

Saddle Detection

3-step Lanczos probe: λmin ≤ ε → evasion

is_saddle, min_eigvec = is_saddle_point(two_loop_fn, dim)
05

Two-Loop Recursion

pk = −Hk gk (with spectral scaling ρkα)
